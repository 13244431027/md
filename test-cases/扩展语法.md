# 扩展语法.md —— 数学公式 / 思维导图 / 脚注 / 代码高亮测试用例

> **引擎配置说明**
> - 解析器：markdown-it + 三个扩展插件（math、mindmap、footnote）。
> - 数学：行内 `$…$`（单行）、块级 `$$…$$`（可跨行）；`\$` 转义后不作为定界符；内容为空白时不解析。

> - 脚注：定义 `[^label]: 内容`，引用 `[^label]`，内联脚注 `^[...]`。

## A. 数学公式 —— 基础命令

<!-- M-01 -->
行内公式：内联 $a^2 + b^2 = c^2$ 结束。

【预期渲染结果】`$…$` 包裹内容渲染为行内 MathML `<math display="inline">`，两侧文字保持行内。

<!-- M-02 -->
分数：$\frac{a+1}{b+2}$

【预期渲染结果】`\frac` 渲染为分数 `<mfrac>`。

<!-- M-03 -->
根式：$\sqrt{x^2+y^2}$ 与 $\sqrt[n]{x}$

【预期渲染结果】`\sqrt{}` 及带可选参数 `\sqrt[n]{}` 渲染为根式。

<!-- M-04 -->
求和 / 积分 / 连乘：
$\sum_{i=1}^{n} i$ 与 $\int_{0}^{\infty} f(x)\,dx$ 与 $\prod_{k=1}^{m} k$

【预期渲染结果】`\sum`、`\int`、`\prod` 渲染为大算子（largeop）。

<!-- M-05 -->
自动大小括符：$\left( \frac{a}{b} \right)$ 与 $\left[ \frac{c}{d} \right]$

【预期渲染结果】`\left … \right` 随内容自动缩放，不要求成对的类型一致但需成对闭合。

## B. 数学公式 —— 矩阵与环境

<!-- M-06 -->
pmatrix：
$$
\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}
$$

【预期渲染结果】`pmatrix` 生成带圆括号 `( )` 的 `<mtable>`。

<!-- M-07 -->
bmatrix：
$$
\begin{bmatrix} a & b \\ c & d \end{bmatrix}
$$

【预期渲染结果】`bmatrix` 生成带方括号 `[ ]` 的矩阵。

<!-- M-08 -->
vmatrix：
$$
\begin{vmatrix} 1 & 2 \\ 3 & 4 \end{vmatrix}
$$

【预期渲染结果】`vmatrix` 生成带竖线 `| |` 的矩阵。

<!-- M-09 -->
cases：
$$
f(x) = \begin{cases} x^2 & x > 0 \\ 0 & x = 0 \end{cases}
$$

【预期渲染结果】`cases` 生成带左花括号 `{` 的多分支结构。

<!-- M-10 -->
未知环境（退化为表格）：
$$
\begin{aligned} a &= 1 \\ b &= 2 \end{aligned}
$$

【预期渲染结果】非上述已知环境时仍输出 `<mtable>`（不含括号装饰）。

## C. 数学公式 —— 文本、希腊字母、关系符、箭头

<!-- M-11 -->
文本与字体：$\text{Hello 世界}$ 与直接 $x+1$

【预期渲染结果】`\text{}` 渲染为普通文本，不当作字母变量斜体。

<!-- M-12 -->
希腊字母：$\alpha \beta \gamma \delta \epsilon \theta \lambda \mu \pi \sigma \omega$

【预期渲染结果】各希腊命令渲染为对应希腊字母。

<!-- M-13 -->
关系符与箭头：$\le \ge \ne \approx \equiv$ 与 $\to \leftarrow \mapsto \Rightarrow \iff \longrightarrow$

【预期渲染结果】关系/箭头命令映射为对应运算符。

<!-- M-14 -->
上下标范围：$x^{2n+1}$、$x_i^j$、$e^{-x}$、$\int_a^b$

【预期渲染结果】`^{}` 组指数、`_` 组下标，短的 `^i`/`_j` 也正确分组。

<!-- M-15 -->
常见函数名：$\sin x \cos y \log z \lim_{x\to0}$ 渲染为直立风格。

【预期渲染结果】`\sin`、`\log` 等渲染为 `mathvariant="normal"` 的直立文字。

## D. 数学公式 —— 定界与边界

<!-- M-16 -->
行内块级：`$$a=b$$` 在段内使用双 `$$`。

【预期渲染结果】行内遇到连续 `$$…$$` 也按显示（display）模式渲染，包裹内容为一个行内显示公式。

<!-- M-17 -->
块级多行：
$$
\int_0^1 x^2 dx =
\frac{1}{3}
$$
结束块级。

【预期渲染结果】`$$…$$` 跨多行时内容整体作为显示公式，内外围不再产生多余空 `<p>`。

<!-- M-18 -->
行内公式禁止含换行（负例）：
这段文本内 $a + b
c + d$。

【预期渲染结果】未闭合/含换行的行内 `$…$` 不被解析为公式，`$` 按普通字符输出（规则：行内遇到换行即视为不成立）。

<!-- M-19 -->
转义美元：`\$100` 与 `$100`；转义后不作为公式定界符。

【预期渲染结果】`\$` 输出字面 `$` 后跟数字，不会被误判为公式起点；裸 `$` 无匹配时按普通文本。

<!-- M-20 -->
空公式与未闭合（负例）：
`$ $`、`$`、`$$`、`$x$` 未完

【预期渲染结果】内容空白或定界符不完整时解析失败，`$`/`$$` 按普通文本输出，不抛错。

<!-- M-21 -->
公式内转义 `\\` 行分隔（矩阵行分隔为此形式，见 M-06~M-10），此句为说明性文字。

## E. 思维导图

<!-- E-01 -->
基础 mindmap：
```mindmap
根节点
  子节点 A
    孙节点 A1
    孙节点 A2
  子节点 B
```

【预期渲染结果】生成 `.mindmap` 结构，缩进决定层级，根节点高亮为蓝色大节点。

<!-- E-02 -->
`mmd` 别名：
```mmd
Root
  Child1
  Child2
```

【预期渲染结果】信息串首词为 `mmd` 时同样渲染为思维导图。

<!-- E-03 -->
多根节点：
```mindmap
根1
  子1
根2
  子2
```

【预期渲染结果】多个顶层节点作为并列的根，分别展开子树。

<!-- E-04 -->
空行与 tab 缩进：
```mindmap
根

	Tab缩进的子节点
		Tab深一层

	另一个子
```
（注意：块内上方使用了真实制表符缩进。）

【预期渲染结果】空行被跳过；制表符按宽度换算为缩进（实现按一个 tab=2 空格处理），层级正确归位。

<!-- E-05 -->
空格缩进与省略列表标记：
```mindmap
Central
  Without Marker
    Leaf One
  With Marker - Star
```
（此例混合了"无列表标记"与 `- ` 标记两种写法。）

【预期渲染结果】`stripMarker` 会剥除行首 `- * +` 或 `数字.` 及后随空格；无标记的缩进文本按节点文字保留，两者可混用。

<!-- E-06 -->
保留文字中的连字符（负例）：
```mindmap
Main
  data-frame
  end-of-line
```

【预期渲染结果】`stripMarker` 仅剥离"行首 + 单个标记 + 空白"；此处 `data-…`、`end-of-line` 中的连字符在文字内部，**不会被误剥**。

## F. 脚注

<!-- F-01 -->
基础脚注：这是正文[^fn1]，后文引用见下面定义。

[^fn1]: 第一个脚注内容。

【预期渲染结果】文内出现 `<sup class="footnote-ref">` 上标，文末生成 `<section class="footnotes">` 列表，定义与引用锚点互链。

<!-- F-02 -->
同一脚注多次引用：第一次[^multi]、第二次[^multi]。

[^multi]: 被引用了两次的内容。

【预期渲染结果】同一标签引用两次时，两处均为上标引用，脚注列表只生成**一项**。

<!-- F-03 -->
内联脚注：行内直接定义脚注^[内联脚注内容]。

【预期渲染结果】`^[...]` 生成脚注引用与该脚注项，无需预先定义。

<!-- F-04 -->
定义在引用之后（定义只在本处之后出现）：
先引用[^late]，定义在下面。

[^late]: 引用出现在定义之后。

【预期渲染结果】脚注定义位于文档后部或引用之后均可解析，顺序不影响渲染。

<!-- F-05 -->
未定义脚注（负例）：
引用未定义的[^missing-def]。

【预期渲染结果】未定义的脚注标签通常按原文本输出（或渲染为无目标链接，取决于引擎），不抛错。

<!-- F-06 -->
脚注内容含复杂 markdown：
文字带脚注[^rich]。

[^rich]: 脚注内容里可以包含 **加粗**、`代码` 与第二行。

【预期渲染结果】脚注定义支持多行与行内 markdown。

## G. 代码高亮语言与边界

<!-- G-01 -->
别名 js（→ javascript）：
```js
const greet = name => `hi ${name}`;
```

<!-- G-02 -->
别名 py（→ python）：
```py
x = [i**2 for i in range(5)]
```

<!-- G-03 -->
别名 html（→ markup）：
```html
<div class="box">ok</div>
```

<!-- G-04 -->
别名 cs（→ csharp）：
```cs
class Foo { public int X { get; set; } }
```

<!-- G-05 -->
别名 c++ / cpp：
```cpp
int main() { std::cout << "hi"; }
```

<!-- G-06 -->
未加载语言（如 no-such-lang）：
```no-such-lang
some content that won't highlight
```

【预期渲染结果】未知语言不报错，按无高亮代码块输出；Prism 自动加载器若开启会尝试拉取，离线时静默降级。

<!-- G-07 -->
无语言标注：本文件 K-02 已覆盖，此处为对照：
```
plain
```

<!-- G-08 -->
错误语言拼写（如 `jave`）与语言混用：
```jave
let a = 1;
```

【预期渲染结果】拼写错误/不存在的语言与"未加载"类似，不做高亮、不抛错。

<!-- G-09 -->
大小写敏感测试：
```HTML
<b>tag</b>
```
（`HTML` 为大写信息串。）

【预期渲染结果】高亮语言信息串对大小写的处理取决于引擎；若大小写不匹配则退回无高亮状态，作为对照记录。
