# 基础语法.md —— CommonMark 标准语法测试用例

> **引擎配置说明（本组用例基于以下行为）**
> - 解析器：markdown-it（CommonMark + 表格 + 删除线扩展）
> - `html: false`：原始 HTML 标签与注释会被**转义为文本显示**，不会被执行。
> - `linkify: false`：裸网址不会自动变成链接，需用 `<https://…>` 或 `[文字](url)`。
> - `typographer: false`：不会把直引号自动替换为弯引号。
> - `breaks: false`：段内换行不会产生 `<br>`，需要在行尾补**两个空格**或反斜杠才硬换行。
> - `~~删除线~~`：支持。
> - 管道表格：支持。
> - 任务列表 `- [x]`：**未注册对应插件**，`[x]` 会按普通文本渲染成列表项文字。
>
> 因 `html:false`，`<!-- 用例编号 -->` 标记会以转义文本 `&lt;!-- … --&gt;` 形式显示在输出里，作为每个用例的分隔与对比参照。
